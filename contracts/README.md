# Theme Funds contracts

Foundry project for the on-chain fund (Phase 7). Network: Monad testnet
(`--rpc-url monad`, chain ID 10143).

Install the standard library once after cloning (it is not committed):

```bash
forge install foundry-rs/forge-std --no-git
```

Build and test:

```bash
forge build
```

```bash
forge test
```
